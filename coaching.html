Not sure where to start?

Start with one session.

I appreciate that options can be overwhelming when you are juggling a lot already, so the Compass session might be a good place to start. We can work together in this longer session to get some clarity around what's taking up all the space, what matters to you most, and what might be getting in the way. Don't worry, you don't need to have the answers to begin, that's what this space is for.
